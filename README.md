快速开始:
1. 直接用浏览器打开 `web/养成框架试玩.html`
2. 或安装 LÖVE 11.x,在 `growth_v0.3/` 放入中文字体 `font.ttf`,运行 `love .`
3. 替换素材:图片按素材 ID 命名放进 `growth_v0.3/assets/`(见 docs/04_素材ID清单.md)

先读 docs/05_技术架构.md 了解代码结构。
