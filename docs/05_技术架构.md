# 技术架构

## 运行方式
- **LÖVE 11.x**:进入工程目录(growth_v0.3 或 battle_v0.2),放一个中文字体命名为 `font.ttf`,执行 `love .`(或把文件夹拖到 love.exe 上)
- **浏览器**:直接打开 `web/` 下的 HTML(需联网加载 Lua 虚拟机与字体)

## 养成框架目录(growth_v0.3)
| 文件 | 职责 |
|---|---|
| main.lua | 入口,注册场景,转发 LÖVE 回调 |
| core/ui.lua | 颜色、字体、文字(含描边字)、按钮、热点、占位框、读图、弹窗、提示条 |
| core/router.lua | 场景切换 `R.go(name, args)` |
| game/state.lua | 全部数值与规则:属性、评级、心情倍率、`S.apply(效果表)` |
| game/flow.lua | 月度流程:新游戏 → 月初事件 → 主界面 → 月末结算 → 结局 |
| data/assets.lua | 素材 ID 与说明 |
| data/activities.lua | 日程活动表 |
| data/story.lua | 序章、月初事件、日常聊天台词 |
| scenes/dialogue.lua | 对话场景(序章与事件共用) |
| scenes/home.lua | 主界面与日程面板 |
| scenes/ending.lua | 结算 |

原则:**内容只改 data/,规则只改 game/state.lua**。

## 数据格式
### 效果表
`{ body=, wit=, emo=, imag=, div=, hum=, exp=, mood=, mora= }`,由 `S.apply` 统一处理:主属性正向收益乘心情倍率;神性、人性、暴露、心情夹在 0–100;返回“智识 +5 心情 −5”式说明文字。

### 活动
`{ name, place, ap, eff, unlock = 第几年开放(可选), say = 她的反应 }`

### 事件
`{ id, when = function(S) return 条件 end, script = 节点数组 或 function(S) return 节点数组 end }`
每个事件只触发一次(标记存在 `S.flags["ev_"..id]`)。

### 对话节点
| 字段 | 说明 |
|---|---|
| who | 说话人;省略为旁白 |
| text | 文本 |
| bg | 背景 ID(沿用到下次修改) |
| portrait | 立绘 ID;`"@calm"` 表示按当前年龄段自动拼 ID;`"none"` 隐藏 |
| choices | `{ { t=选项, eff=效果, flag={键,值}, say=选后旁白 } }` |

## 读图机制
`U.image(id)` 在 `assets/` 查找 `id.png/.jpg/.jpeg`,找不到按回退规则逐级查找;`U.portrait` 等比缩放、底部对齐,`U.background` 铺满。没有图片时显示带 ID 的虚线占位框。

## 网页版构建(tools/)
- `prelude.lua`:用 JS 画布实现 LÖVE 的最小接口(图形、字体、鼠标、读图)
- `shell.html`:页面模板,内含 JS 侧绘图函数、鼠标事件、本地图片载入
- `build_web.py`:把工程打包成单个 HTML,工程内模块注册到 `package.preload`
  ```
  python tools/build_web.py growth_v0.3 web/养成框架试玩.html "标题" "说明"
  ```
- 新增 LÖVE 接口时,需在 prelude.lua 加 Lua 侧包装,并在 shell.html 用 `reg('_js_xxx', ...)` 注册同名函数


## 迁移到千星奇域的对应关系(建议)
| 原型 | 千星奇域 |
|---|---|
| game/state.lua 的 S.st、S.flags | 全局变量 |
| data/*.lua 的表 | 配置数据 / 预设 |
| game/flow.lua 的月度循环 | 节点图主循环 |
| scenes/* | 界面与关卡状态 |
| 素材 ID | 编辑器内资源引用 |

编辑器的具体能力(自定义界面、回合制支持等)需要在千星沙箱中逐项确认。
