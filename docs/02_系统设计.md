# 系统设计

## 1. 时间与行动力
- 一回合 = 一个月,共 36 回合(三年):第 1 年幼年、第 2 年少年、第 3 年青年
- 每月 13 点行动力,月末作废;月末扣生活费、恢复心情
- 月初先检查事件,再进入主界面

## 2. 养成
- 四主属性:体魄、智识、情感、想象;评级 E/D/C/B/A/S,界面显示“还差多少”到下一级
- 双轨:神性、人性(0–100);暴露度(0–100,满即失败);心情(0–100)
- 成长倍率:心情 ≥70 为 ×1.2,<30 为 ×0.5
- 课程分修行类(加神性与暴露)和日常类(加人性与心情)

## 3. 日程(七国课程 + 打工 + 修行 + 休息)
| 地点 | 方向 | 主要成长 |
|---|---|---|
| 蒙德 | 吟游 | 情感、想象 |
| 璃月 | 契约 | 智识 |
| 稻妻 | 剑术 | 体魄 |
| 枫丹 | 戏剧 | 情感、想象 |
| 须弥 | 学术(第 2 年) | 智识、神性,+暴露 |
| 纳塔 | 竞技(第 2 年) | 体魄 |
| 打工 | 万民堂、冒险家协会 | 摩拉 |
| 秘密 | 修行权能 | 神性,+暴露 |
| 休息 | 散步 | 心情、人性 |

主界面热点(各 1 行动力):读书(+智识)、陪她玩(+情感 +心情)、藏起沙漏(−暴露度)。点女儿聊天每月一次 +情感 +心情。

## 4. 事件
- 月初触发,条件为函数(年、月、属性、标记),每个事件只触发一次
- 已实现:序章(捡到孩子)、第一个夜晚、第一句话、“你是我的什么”(决定父亲身份:守护者/引路人/同行者)、天钉冷光(按暴露度分支)、第 2/3 年成长事件
- 规划:双数月“女儿的心事”、天理巡检节点(第 6/12/24/36 月)

## 5. 父亲系统
- 序章选择出身:退役冒险家(体魄起点高)、落魄学者(智识起点高)、商人(初始摩拉多)
- 第 4 个月决定身份目标,影响她对父亲的评价与后续结局
- 规划:信任值,决定关键时刻她是否听你的

## 6. 探险与战斗(战斗原型 v0.2)
- 探险:选图后走 5 层节点(战斗/事件/休息/宝箱/首领),路线决定遭遇
- 战斗:回合制,全队共用能量(每回合 +3,上限 6,可结余);每人每回合用一个技能
- 伤害 = 攻击 × 攻击倍数;状态:灼烧(每层每回合 6 伤害,结算后 −1)、眩晕/石化、护盾、攻击提升
- 敌人显示下回合意图:攻击、狙击(打血最少者)、群攻、蓄力 → 重击
- 伊斯塔露的迟滞、回溯会增加暴露度,与养成主线联动
- 探险事件带属性检定(如“智识 ≥130”),成败效果不同

## 7. NPC 与好感(规划)
- 按国家分布 15–20 位;好感四档:认识 → 友人 → 挚友 → 羁绊
- 每人三样偏好(花、料理、物品),羁绊后触发赠礼与结局线
- 阵营声望(骑士团、教令院、愚人众等)与个人好感并行,部分阵营互斥
- 友人以上可邀请为探险伙伴(最多 2 名)

## 8. 经济、物品与家园(规划)
- 摩拉用于学费、礼物、服装;烹饪与炼金是送礼主要来源
- 神性物品(权能碎片、时之晶)只能通过修行或探险获得
- 服装三态:日常、正装、神性形态

## 9. 职业结局表(规划)
| 星级 | 职业示例 |
|---|---|
| 五星 | 执行官、大风纪官、七星席位、骑士团团长级、教令院贤者级 |
| 四星 | 千岩军统领、审判官、歌剧院明星、往生堂堂主级 |
| 三星 | 药师、铁匠、厨师、商人、吟游诗人 |
| 二星以下 | 普通职业、无业 |

判定 = 属性门槛 + 组织声望 + 阵营冲突。女儿各有天然加成(伊斯塔露偏钟表匠、历史学者、研究者)。
