# 素材 ID 清单

代码中所有占位框都按素材 ID 显示。把图片命名为 `素材ID.png`(或 .jpg)放进工程的 `assets/` 文件夹即可替换;网页试玩版用“选择本地图片”按钮载入。LÖVE 不支持 .webp。

## 回退规则
找不到某个 ID 时逐级去掉末段再找:`ist_child_happy` → `ist_child` → `ist`。
只放 `ist.png` 即可覆盖所有伊斯塔露立绘;放 `ist_child` / `ist_teen` / `ist_adult` 可按年龄段区分。

## 养成框架
### 立绘(建议透明底 PNG,竖构图)
| ID | 说明 |
|---|---|
| ist_child_sleep | 幼年 · 熟睡,蜷缩,怀抱停摆的沙漏 |
| ist_child_calm / happy / sad | 幼年 · 平静 / 开心 / 不安 |
| ist_teen_calm / happy / sad | 少年 · 平静 / 开心 / 不安 |
| ist_adult_calm / happy / sad | 青年 · 平静 / 开心 / 不安 |

主界面按“年龄段 + 心情”自动选 ID:心情 ≥70 happy,35–69 calm,<35 sad。

## 立绘规划(三阶段)
- 幼年 6–8 岁,约 3 头身;少年 12–14 岁,约 5 头身;青年 18–20 岁,约 7 头身
- 每阶段表情:幼年 5 个、少年与青年各 7 个;服装三态:日常、正装、神性形态
- 三阶段固定特征:发饰位置、瞳孔形状、沙漏挂法(幼年挂颈、少年腰挂、青年悬浮)
