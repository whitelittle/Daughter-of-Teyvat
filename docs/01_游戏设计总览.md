# 天理的女儿 · 游戏设计总览

## 核心概念
玩家是提瓦特的一名普通人,在天钉坠落的山谷里捡到一个失去神格的孩子——被天理“断联”的影之一。玩家用三年时间把她抚养成人,同时躲避天理的回收。

- 类型:日程养成 + 属性成长 + 随机事件 + 多结局,附带探险回合制战斗
- 首发女儿:伊斯塔露(时之执政)。其余三位(纳贝里士、若娜瓦、阿斯莫代)作为后续角色线
- 最终平台:原神千星奇域(导出 .gia)。本目录中的 Lua 工程是规则验证原型

## 四位女儿的差异(规划)
| 女儿 | 独特机制 | 主题 |
|---|---|---|
| 伊斯塔露(时) | 回溯:有限次数撤销/重来 | 记忆与失去 |
| 纳贝里士(生) | 双魂:两个人格分别培养 | 造物与自我 |
| 若娜瓦(死) | 亡者对话:获取隐藏情报与遗物 | 终结与告别 |
| 阿斯莫代(空) | 空间跳跃:快速移动、躲避追捕 | 孤独与归属 |

## 核心张力
- **神性 ↔ 人性**:神性高则强大,但会引来天理;人性高则安全,但失去权能
- **暴露度**:神性外泄会累积,满 100 即被天理察觉(失败)
- **心情**:影响成长倍率,逼迫玩家在“练”和“歇”之间取舍
- **摩拉**:课程要学费,打工赚钱但不长主属性

## 结局结构(规划)
优先级:命运层 > 情感层 > 职业层,外加“路人结局”兜底。
- 命运层(约 5):回归、叛离、融合、凡人、隐藏结局
- 情感层(约 12):各 NPC 羁绊线,单人与多人结局并存
- 职业层(约 20–30):属性门槛 + 组织声望 + 关键选择

## 开发顺序建议
1. 时间与行动力、四属性与课程(已完成 v0.3)
2. 一张探险图 + 回合制战斗(战斗原型 v0.2 已完成,待接入)
3. 5–8 位 NPC 的好感与赠礼
4. 结局判定
