# 天理的女儿 · 养成框架 v0.3

运行:安装 LÖVE 11.x,把中文字体改名为 font.ttf 放进本文件夹,然后 `love .`。

## 流程
序章(捡到孩子) → 每月:月初事件 → 主界面安排 → 结束本月 → … → 第 36 个月后结算。

## 改内容只需要动 data/
- data/assets.lua     所有立绘、背景的占位 ID 与说明(替换素材按 ID 对应)
- data/activities.lua 日程活动(行动力、学费/收入、效果、开放年份、她的反应)
- data/story.lua      序章、月初事件(触发条件 + 对话脚本)、日常聊天台词

## 数值规则在 game/state.lua
- 每月 13 行动力,生活费 30,月末心情 +8
- 心情 ≥70 成长 ×1.2,<30 成长 ×0.5
- 评级:E 0 / D 30 / C 70 / B 120 / A 180 / S 250
- 暴露度满 100 直接失败

## 放入自己的图片
把图片按素材 ID 命名放进 assets/ 文件夹即可替换占位框,详见 assets/放图说明.txt。
找不到时会逐级退回(ist_child_happy → ist_child → ist),只放一张 ist.png 也能用。
