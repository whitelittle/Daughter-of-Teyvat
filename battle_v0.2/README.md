# 天理的女儿 · 探险战斗原型 v0.2

运行:安装 LÖVE 11.x(https://love2d.org),把一个中文字体改名为 `font.ttf` 放进本文件夹,然后把文件夹拖到 love 程序上(或命令行 `love .`)。

战斗布局:上方战场,下方能量条 + 三张角色卡(头像、攻击、护盾、HP、三个技能),左下是技能说明。

规则:
- 能量全队共用,每回合 +3,最多存 6 点;技能右侧圆圈是能量消耗。
- 每名队员每回合用一个技能,用完显示[回合结束]。
- 伤害 = 攻击 × 攻击倍数。灼烧每层每回合 6 伤害,结算后层数 -1。
- 伊斯塔露的迟滞、回溯会增加暴露度,满 100 立即失败。
- 立绘与敌人是占位图形。

调数值:改 main.lua 顶部的 CFG 表和 HEROES / FOES 表。
